🌿 Epifitas.cl

Este sitio ha sido creado para difundir el conocimiento sobre las plantas que habitan en el perfil vertical de los bosques chilenos. Queremos despertar el interés del público por aquellos organismos que son un componente importante pero muchas veces obviado de nuestros bosques: epífitas, trepadoras y hemiepífitas.

Mediante información científica, fotos e ilustraciones buscaremos mostrar la belleza e importancia de este grupo de especies.

¡Esperamos que disfruten el sitio y que comiencen a observar los bosques desde una nueva perspectiva!

— Los autores

Rasgos ecológicos y funcionales de las especies documentadas en este sitio. Los rasgos cuantitativos (altura de planta, área foliar, SLA, masa de semilla, densidad de madera) provienen de bases de datos externas — ver la nota de fuentes al final de la página.

//| echo: false
rasgos = d3.csv("data/rasgos.csv", d3.autoType)
//| echo: false
viewof formaSel = Inputs.checkbox(
  [...new Set(rasgos.map((d) => d.growth_form))],
  { label: "Forma de crecimiento", value: [...new Set(rasgos.map((d) => d.growth_form))] }
)
//| echo: false
viewof familiaSel = Inputs.select(
  [...new Set(rasgos.map((d) => d.family))].sort(),
  { label: "Familia", multiple: true }
)
//| echo: false
viewof textoRasgos = Inputs.text({ label: "Buscar", placeholder: "Especie, estado de conservación…" })
//| echo: false
filtrados = rasgos.filter((d) => {
  const famOk = familiaSel.length === 0 || familiaSel.includes(d.family);
  const txt = textoRasgos.trim().toLowerCase();
  const txtOk =
    txt === "" ||
    Object.values(d).join(" ").toLowerCase().includes(txt);
  return formaSel.includes(d.growth_form) && famOk && txtOk;
})
//| echo: false
slugPorEspecie = new Map(rasgos.map((d) => [d.species, d.slug]))
//| echo: false
Inputs.table(filtrados, {
  columns: [
    "species", "growth_form", "family",
    "phenology_flowering", "phenology_fruiting", "conservation_status",
    "plant_height_m", "seed_mass_mg", "wood_density_g_cm3", "trait_source"
  ],
  header: {
    species: "Especie",
    growth_form: "Forma de crecimiento",
    family: "Familia",
    phenology_flowering: "Floración",
    phenology_fruiting: "Fructificación",
    conservation_status: "Estado de conservación",
    plant_height_m: "Altura (m)",
    seed_mass_mg: "Masa semilla (mg)",
    wood_density_g_cm3: "Densidad madera (g/cm³)",
    trait_source: "Fuente rasgos"
  },
  format: {
    species: (s) =>
      html`<a href="especies/${slugPorEspecie.get(s)}.html"><i>${s}</i></a>`,
    plant_height_m: (v) => v == null ? "—" : v,
    seed_mass_mg: (v) => v == null ? "—" : v,
    wood_density_g_cm3: (v) => v == null ? "—" : v
  },
  rows: 15,
  sort: "species"
})

Fuentes de los rasgos cuantitativos

Nota
  • Rasgos-CL (Alfaro et al. 2023, Global Ecology and Biogeography): base de rasgos funcionales de plantas leñosas de Chile, incorporada directamente desde su repositorio público.
  • BIEN (Botanical Information and Ecology Network): consultada vía el paquete de R BIEN para especies no leñosas o herbáceas que Rasgos-CL no cubre.
  • Especies sin dato en ninguna de las dos fuentes (frecuente en helechos) se marcan como “Pendiente” o “Sin dato” en la columna Fuente rasgos, en vez de dejarse en blanco.

¿Cómo participar?
  1. Instala la app de iNaturalist o usa el sitio web.
  2. Fotografía la planta (hoja, flor o fruto ayudan a la identificación) y registra la ubicación.

Las epífitas son plantas que crecen sobre otras plantas, usándolas como soporte y siendo capaces de desarrollar todo su ciclo de vida sobre ellas.

Nota

A diferencia de las plantas parásitas, las epífitas no extraen nutrientes directamente del tejido vivo de su hospedero. Para sobrevivir en lo alto del dosel, han desarrollado diversas adaptaciones para capturar humedad atmosférica, almacenar agua y retener materia orgánica.

Especies epífitas

Las hemiepífitas son plantas que desarrollan solo una etapa de su ciclo vital como epífitas. Se dividen comúnmente en hemiepífitas primarias (germinan en el dosel y luego envían raíces al suelo) y secundarias (germinan en el suelo y posteriormente pierden su conexión subterránea).

Especies hemiepífitas

Nota

Actualmente ninguna de las especies con ficha en el sitio presenta un hábito estrictamente hemiepífito. A medida que se incorporen nuevas fichas de hemiepífitas (por ejemplo, del género Hydrangea), aparecerán listadas aquí.

Las trepadoras y lianas son plantas con tallos flexibles que germinan en el suelo del bosque y se apoyan o sujetan de árboles y arbustos para alcanzar la luz en el dosel.
